Medarbejderne scanner pakkens stregkode med telefonens kamera. Der gemmes hvem, hvornår og hvor den blev afleveret – også selvom nettet er væk. På computeren kan man se det hele.

Sådan virker den

Tre ting – og det er det

IND

Pakken kommer

Tryk "Scan ind" og hold kameraet mod stregkoden. Den læses automatisk med et bip, og så er man klar til den næste.

UD

Pakken afleveres

Tryk "Scan ud", scan koden og vælg hvor den blev afleveret. Tag evt. et billede som bevis og skriv en note.

PC

Overblik på computeren

Se alle scanninger, søg på en stregkode, se en pakkes historik og hvilke pakker der er inde lige nu.

Mobilen

Hurtig scanning i serie

Det er en webside, som kan gemmes på hjemmeskærmen. Folk åbner bare et link og logger ind.

  • Læser almindelige stregkoder (EAN-13, Code 128 m.fl.)
  • Koden skal læses to gange ens, så fejllæsninger undgås
  • Kan ikke koden læses, tastes nummeret ind
  • Advarsel hvis pakken aldrig er scannet ind eller allerede er ude
Computeren

Alt samlet ét sted

Kun administratorer kan se oversigten.

  • Filtrér på dato, medarbejder, ind/ud og advarsler
  • Søg på stregkode, sted eller note
  • Klik på en pakke og se hele dens historik
  • Fane med pakker, der er inde lige nu
  • Se billederne fra afleveringen
  • Download som Excel – alle scanninger og status pr. pakke
Indstillinger

Telefonerne på med én QR-kode

Kameraet kræver en sikker https-forbindelse. Pakkescanner laver den selv gennem Cloudflare – gratis og uden at røre routeren.

  • Hurtig adresse med det samme, uden konto
  • Eller din egen faste adresse, fx pakker.ditfirma.dk
  • Scan QR-koden, log ind og læg den på startskærmen
Brugere og steder

Styr det hele fra oversigten

  • Opret medarbejdere med eget login
  • Scannere kan kun scanne – administratorer ser det hele
  • Ny kode eller deaktivér med ét klik
  • Faste afleveringssteder vises som forslag på telefonen
Uden internet

Intet går tabt, når nettet ryger

På lageret, i kælderen eller ude på ruten – man kan bare blive ved med at scanne.

1

Gemmes først på telefonen

Hver scanning (også billedet) lægges i telefonens kø, før den sendes.

2

Sendes af sig selv

Så snart der er net igen, sendes køen. Man skal ikke gøre noget.

3

Aldrig to gange

Hver scanning har sit eget id, så serveren gemmer den kun én gang.

4

Rigtigt tidspunkt

Tiden er den, hvor der blev scannet – ikke hvornår den nåede frem.

Installér

Kører på din egen server

Pakkescanner installeres på en Windows-pc eller -server i firmaet. Den kører i baggrunden og starter selv, når computeren tænder. Alle data bliver hos dig.

Hent Pakkescanner 1.1
  • Windows 10, 11 eller Server – alt andet er med i programmet
  • Daglig backup af databasen, de seneste 30 dage
  • Opdatering: kør den nye version – data bevares
  • Linux eller Mac: kør den med Node.js 24 – se vejledningen
  1. Hent og kør opsætningsprogrammet på serveren, og tryk Installér. Siger Windows "beskyttede din pc", så tryk Flere oplysninger → Kør alligevel.
  2. Opret dig selv som administrator i browseren, der åbner.
  3. Vælg under Indstillinger, hvordan telefonerne skal forbinde, og scan QR-koden.
  4. Opret medarbejdere og afleveringssteder – så er I i gang.
